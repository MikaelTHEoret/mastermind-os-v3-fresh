# MasterMind OS

🌀 **Neural Orchestration Platform for Sovereign Scroll Development**

## Overview

MasterMind OS is an advanced development environment for creating and managing sovereign scrolls (mathematical consciousness frameworks). It integrates consciousness-responsive technology with traditional development workflows.

## Features

- **Scroll Forge IDE**: Complete development environment for scroll creation
- **Stack Auth Integration**: Secure authentication and user management  
- **Wallet Integration**: MetaMask and Web3 wallet support
- **IPFS Integration**: Decentralized file storage via Pinata
- **GitHub Sync**: Version control and collaboration
- **NFT Minting**: Deploy scrolls to Ethereum L1 and Scroll L2

## Technology Stack

- **Frontend**: Next.js 15, React 18, TypeScript
- **UI**: Tailwind CSS, shadcn/ui components
- **Authentication**: Stack Auth
- **Blockchain**: ethers.js, MetaMask
- **Storage**: IPFS via Pinata
- **Deployment**: Vercel

## Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to access the development environment.

## Architecture

The application follows a clean architecture pattern with:
- Component-based UI design
- Type-safe TypeScript implementation
- Responsive design for all screen sizes
- Real-time state management
- Error boundaries and graceful fallbacks

## Authentication

Stack Auth provides secure user authentication with features:
- Email/password signup and signin
- Password reset functionality  
- User profile management
- Session persistence

## Development Workflow

1. **Create Scrolls**: Use the built-in JSON editor
2. **Upload to IPFS**: Decentralized storage via Pinata
3. **Version Control**: Sync with GitHub repositories
4. **Mint NFTs**: Deploy to blockchain networks
5. **Manage Projects**: Organize and track scroll development

## Deployment

The application is deployed on Vercel with:
- Automatic deployments from GitHub
- Environment variable management
- Preview deployments for pull requests
- Production optimizations
